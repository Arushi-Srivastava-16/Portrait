# Portrait Images

Place your portrait images here:

## Required Images

For each portrait, you need:
- `{portrait-id}-sleep.png` - Static image when portrait is sleeping
- `{portrait-id}-awake.gif` - Animated GIF when portrait is speaking

## Portrait IDs

- `fat-lady-sleep.png` / `fat-lady-awake.gif`
- `sir-cadogan-sleep.png` / `sir-cadogan-awake.gif`
- `headmaster-sleep.png` / `headmaster-awake.gif`
- `mermaid-sleep.png` / `mermaid-awake.gif`
- `ambrose-sleep.png` / `ambrose-awake.gif`

## Default Fallback

If images are not found, the app will try to use `default-sleep.png` as a fallback.
